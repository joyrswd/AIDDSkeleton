# システム文書索引

## 概要

本プロジェクトは AIDD Skeleton の動作確認を目的とする、ローカル実行可能な Todo アプリケーションである。

## 責任境界

- `plans/apps/todo/`: Todo の要件、設計、テスト方針、トレーサビリティ
- `products/apps/todo/`: アプリケーション、API、データベース初期化、テスト
- 対象外: 公開運用、認証、監視、バックアップ運用、デプロイ

## 読む順序

1. [ドキュメント言語](documentation_language.md)
2. [現在の状態](../CURRENT_STATUS.md)
3. [Todo アプリ索引](../apps/todo/todo_index.md)

## ライフサイクル

状態は「初期化済み」「実装中」「検証済み」の順に進む。要件・受入基準、責任境界、設計、検証方法が確定し、未解決の阻害事項がないことを実装開始条件とする。実装と設定が揃い、所定の検証が成功し、文書・実装・状態・トレーサビリティが一致した時点を完了とする。終了境界はローカル実行可能な成果物、テスト、手順の引き渡しである。

セキュリティ、プライバシー、アクセシビリティ、性能、可用性、監視、保持、復旧、ライセンスの扱いは [Todo 要件](../apps/todo/requirements/todo_requirements.md) に記載する。
