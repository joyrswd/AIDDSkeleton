# システム索引

## 概要

本プロジェクは、AIDD スケルトンの開発フローを検証するためのローカル Todo Web アプリケーションである。

## 責任境界

- `todo` アプリケーションが画面、PHP API、SQLite 永続化、アプリ固有テストを所有する。
- 外部サービス、認証、配備、本番運用は対象外とする。
- ライフサイクルはローカルでの実装と検証で終了し、公開・運用・廃止は後続決定とする。

## 実装開始・完了条件

実装は、要件と受入条件、責任境界、設計、検証方法が定義され、未解決のブロッカーがない場合に開始できる。完了には実装と設定、定義した検証、要件・設計・テスト・実装の整合、状態とトレーサビリティの更新を必要とする。
