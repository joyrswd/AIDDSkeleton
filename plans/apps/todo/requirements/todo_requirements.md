# Todo 要件

## 機能要件

- **REQ-01**: 利用者は空でないタイトルの Todo を作成し、再読み込み後も参照できる。
- **REQ-02**: 利用者は Todo のタイトルと完了状態を変更できる。
- **REQ-03**: 利用者は Todo を削除できる。
- **REQ-04**: 利用者は全件、未完了、完了で一覧を絞り込める。
- **REQ-05**: 画面は保存失敗を通知し、操作中状態と件数を表示する。

## 品質と制約

- **REQ-06**: JSON API は入力を検証し、SQLite 操作にプリペアドステートメントを使用する。
- **REQ-07**: フォームラベル、フォーカス表示、キーボード操作、ライブ通知を備える。
- **REQ-08**: PHP 8.1 以上と PDO SQLite のローカル環境で、外部依存なしに起動できる。

## 受入基準

作成、一覧、編集、完了切替、削除が実データベースを使う自動テストで成功し、HTTP 経由で画面と API が応答すること。空タイトルは 422、存在しない ID は 404 となること。JavaScript と PHP の構文検査が成功すること。

## 適用範囲の判断

入力検証などの基本セキュリティと基本アクセシビリティは適用する。Todo に個人情報を入れない前提でプライバシー管理は対象外。小規模ローカル利用のため性能 SLA、可用性、監視、保持期限、バックアップ・復旧運用は対象外。ライセンスはリポジトリの MIT License に従う。認証、複数ユーザー、同期、期限、タグ、優先度、添付、公開運用は対象外である。

未解決の質問はない。対象外機能が必要になった時点で要件変更として判断する。
